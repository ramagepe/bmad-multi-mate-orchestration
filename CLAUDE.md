# CLAUDE.md — BMO Module Development Rules

This repo (`bmad-multi-mate-orchestration`) is the **source repository** for the BMO (Multi-Mate Orchestration) custom BMAD module.

## Critical: `src/` is the canonical source

- `src/` contains the **module source** — this is what the BMAD installer copies to target projects.
- `_bmad/bmo/` contains the **installed copy** for this repo's own use. It is generated by the installer and can be overwritten at any time.

### Rules

1. **Always edit `src/` first.** Any change to workflows, step files, agent definitions, or contracts must be made in `src/` before anywhere else.
2. **Never edit only `_bmad/bmo/`.** Changes there will be lost on the next install/reinstall.
3. **After editing `src/`, re-install the module** in the target project to propagate changes.
4. **After install, verify propagation.** Check that your changes actually made it to `_bmad/bmo/` in the target repo. The installer may overwrite source files under certain conditions.
5. **If both `src/` and `_bmad/bmo/` need the same change**, edit `src/` first, then install. Do not manually copy files — use the installer to maintain the real workflow.

### File mapping

| Source (edit here) | Installed copy (generated) |
|---|---|
| `src/module.yaml` | `_bmad/bmo/config.yaml` (transformed) |
| `src/agents/*.agent.yaml` | `_bmad/bmo/agents/*.md` (transformed) |
| `src/workflows/**/*.md` | `_bmad/bmo/workflows/**/*.md` (copied) |
